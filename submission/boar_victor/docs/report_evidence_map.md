### Limite ale dovezilor

GUI DBeaver și restaurarea nativă a dumpurilor sunt netestate. Capturile sunt rezultate CLI, nu screenshots DBeaver. Fingerprintul business actual înainte/după este `74d4a44650b438f64ef7f010e9bce2893b68ac7483072a9ca2483e08aaa520c8`, prin EXACT `phase3_runner.business`: SELECT * ORDER BY 1,2 din 11 tabele, JSON ensure_ascii=False/sort_keys=True, SHA-256; query_params separat. În plus, structura/parametrii sunt comparați separat și identici. `postflight.json`, `main_business_before/after.json` și `main_structure_before/after.json` sunt dovezile proiectului; pachetul omite copiile administrative redundante ale datelor principalei. Metadatele fără date de business sunt distribuite în `evidence/schema_metadata.json`, iar cele trei rezumate istorice în `evidence/historical_summaries/`; afirmațiile raportului sunt validate prin sursele primare, nu doar prin rezumate.

Demonstrația NOUĂ read-only Q2 fără coalescing se află în `replay_package_1/q2_without_coalescing.sql` / `.json` (în ZIP `evidence/replay/`). Actual greșit: H05 `[2025-07-01,2026-07-01)` și `[2026-07-01,9999-12-31)`; expected independent: un mandat `[2025-07-01,9999-12-31)`. Este declarată ca demonstrație a auditului final, separat de încercările istorice cu ERROR 1111/1267. Nicio eroare neașteptată nu este transformată în PASS.

### Surse suplimentare oficiale / comparația motoarelor

- Oracle [Flashback / Temporal Validity](https://docs.oracle.com/en/database/oracle/oracle-database/26/adfns/flashback.html): VT separat de istoria TT și retenție. URL-ul cerut pentru documentația 23 redirecționează la 26; nu se pretinde un test Oracle local.
- Microsoft [Temporal tables](https://learn.microsoft.com/en-us/sql/relational-databases/tables/temporal-tables) și [limitations](https://learn.microsoft.com/en-us/sql/relational-databases/tables/temporal-table-considerations-and-limitations): TT la începutul tranzacției UTC; protecția coloanelor/istoriei când SYSTEM_VERSIONING este activă.
- PostgreSQL [18 CREATE TABLE](https://www.postgresql.org/docs/18/sql-createtable.html): WITHOUT OVERLAPS și acoperire prin PERIOD FK pe range/multirange.
- PostgreSQL [19 temporal tables](https://www.postgresql.org/docs/19/ddl-temporal-tables.html) / [UPDATE](https://www.postgresql.org/docs/19/sql-update.html): pagina consultată se declară unsupported/development, TT nu este nativ, iar UPDATE nu confirmă FOR PORTION OF. Formularea anticipativă din Assignment1 p. 6 este tratată explicit ca perspectivă a materialului, nu facilitate stabilă demonstrată.
